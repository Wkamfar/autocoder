# POSE On‑Chain Verification (Wire2)

Wire2 is a reference application. These documents specify how Wire2 anchors end‑to‑end evidence onto the POSE blockchain without leaking PII.

## Documents

- `MASTER_PROOF_MATRIX.md`: single master matrix (event types × rails × required fields × signatures × anchor policy × verifier rules)
- `POSE_ONCHAIN_EVIDENCE_MODEL.md`: evidence envelope + signatures + hash/merkle structure
- `ONCHAIN_CONTRACT_SPEC.md`: contract interface and event model for anchoring
- `UNIFIED_VERIFIER_SPEC.md`: how verification works across all rails
- `PROOF_LIFECYCLE_WIRE_ACH.md`: end‑to‑end proof lifecycle for WIRE/ACH
- `PROOF_LIFECYCLE_CASH.md`: end‑to‑end proof lifecycle for CASH
- `PROOF_LIFECYCLE_BTC.md`: end‑to‑end proof lifecycle for BTC
- `PROOF_LIFECYCLE_ETH.md`: end‑to‑end proof lifecycle for ETH
